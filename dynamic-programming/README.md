# helpNow — Recomendação de Voluntários (Dynamic Programming)
1. Requisitos: Python 3.10+ e Jupyter (`pip install notebook matplotlib`).
2. Na pasta `dynamic-programming/`, rode `jupyter notebook helpnow_recomendacao.ipynb`.
3. Execute todas as células (Kernel > Restart & Run All); os dados são simulados com semente fixa.
4. Saídas: recomendações por solicitação, testes automáticos e gráfico de desempenho.
